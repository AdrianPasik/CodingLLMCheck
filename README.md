# CodingLLMCheck
Check if some latest Coding LLM does not make silly mistakes. Every error which i stumbled upon when used Coding LLMs.
Whenever I see promising new LLM - I run those checks first.

## Prerequisities
```bash
pip install requests, colorama
```

### Run python scripts that end with *-check
This will give you examples of hallucinations/obvious mistakes that LLM's did.
